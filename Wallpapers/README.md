# Wallpapers do bot

Envie imagens pela seção **Avisos** do painel web. O painel grava os arquivos nesta pasta com numeração sequencial, começando pelo próximo dia livre a partir do wallpaper atual (por exemplo, `1.png`, `2.jpg`, `3.gif`).

Também é possível copiar arquivos manualmente para esta pasta, usando nomes de `1` a `105` com extensão `.png`, `.jpg`, `.jpeg`, `.webp` ou `.gif`. O bot publica um por dia no canal configurado e só avança para o próximo depois do envio bem-sucedido. Cada upload pelo painel pode ter até 25 MiB.
